Project Title: Stacks and Queues: Array vs. Linked List
Description:
This project demonstrates the implementation of stacks and queues using arrays and linked lists. It includes basic operations such as insertion, removal, checking elements, and displaying the current data structure.
Files Included:
array_stack.py - Arracy based stack
linked_stacked.py - Linked-list-based-attck
array_queue.py - Circular array queue 
linked_queue.py - Linked-list-based queue
main.py - Menu-driven test program
analysis.md - Written analysis 

How to Run:
1. Save all Python files in one folder.
2. Open the folder in VS Code or IDLE.
3. Run main.py.
4. Choose a data structure. 
5. Select an operation.
6. Follow the instructions displayed.
